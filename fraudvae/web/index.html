Score a transaction

The model reconstructs the transaction from a 20-dimensional summary of what normal traffic looks like. What it fails to reconstruct is what it finds suspicious.

Load an example from the held-out data:

No transaction scored yet.

Fill in what you know and press Score transaction.

Bars: each field's share of the reconstruction error.

validation sample, PCA of the posterior means
Score a whole file instead

A CSV using the unified column names (see How it works). Rows get a score, a percentile and a flag at the alert budget above. If an is_fraud column is present you also get AUROC / recall for the file.

Training data

Eleven public transaction datasets mapped onto one schema. Where a source has no notion of a field, the field is marked unobserved and the model's likelihood skips it.
