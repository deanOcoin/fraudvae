Score a transaction

The model reconstructs the transaction from a 20-dimensional summary of what normal traffic looks like. What it fails to reconstruct is what it finds suspicious.

Customer history (v5: what the sequence model sees)

Either paste the customer's previous transactions as JSON, oldest first — a list of {"features": {...same field names...}, "secs_before": 3600} (or "ts" in epoch seconds) — or give a customer id and the server will remember every transaction it scores for that id and use them as history next time.

Device payload (v5: what the device head sees)

Telemetry as the browser or app reports it; the server maps it onto the device block. Keys: os, browser, device_type, screen, session_length_min, keep_alive, phone_valid, email_domain, recipient_email_domain, name_email_similarity, account_age_days, foreign. Fields set in the form win.

Text payload (v5: what the text heads read)

Free text on the transaction: url (the url head), description / memo / message (the free-text head, trained on scam postings), profile / bio (the profile head). Each answers with a likelihood ratio that is added to the blend's log-odds; nothing in the training data had text, so this never changes a held-out number.

Session events (v5: what the behaviour verifiers see)

Raw interaction events per modality: mouse rows [t, x, y, kind], keystroke rows [t, key, down|up], touch rows [t, x, y, pressure, size, action], motion rows [t, x, y, z]. With a customer id the server compares the session with that customer's enrolled profile (built from their earlier sessions) and enrols this one; the first session only enrols.

Score a whole file instead

A CSV using the unified column names (see How it works). Rows get a score, a percentile and a flag at the alert budget above. If an is_fraud column is present you also get AUROC / recall for the file.

Training data

Eleven public transaction datasets mapped onto one schema. Where a source has no notion of a field, the field is marked unobserved and the model's likelihood skips it.
