## fdh: Fraud Detection Handbook simulated card transactions

simulated point of sale card payments, 5k customers x 10k terminals, 183 days, 3 fraud scenarios.

- source: <https://github.com/Fraud-Detection-Handbook/simulated-data-raw>
- license: GPL-3.0 (handbook code) / see repo
- files: `simulated-data-raw/data/2018-04-01.pkl`
- notes: one pickle per day. scenario 1 = any amount > 220, 2 = compromised terminal, 3 = compromised card (amounts x5)

Built: 1,754,155 rows, 14,681 fraud.

Fields observed: `amount`, `hour`, `dow`, `secs_since_prev_txn`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `cust_amount_mean_30d`, `amount_over_cust_mean`, `merch_txn_count_24h`, `channel`, `txn_type`

## capone: Capital One synthetic card transactions

synthetic US credit card authorisations for 5k accounts over 2016, with reversals and address verifications.

- source: <https://github.com/CapitalOneRecruiting/DS>
- license: unspecified, public recruiting dataset
- files: `DS/transactions.zip`
- notes: json lines inside transactions.zip. cvv entered vs on card, pos entry mode, credit limit / available money

Built: 786,363 rows, 12,417 fraud.

Fields observed: `amount`, `hour`, `dow`, `secs_since_prev_txn`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `cust_amount_mean_30d`, `amount_over_cust_mean`, `merch_txn_count_24h`, `credit_limit`, `amount_over_limit`, `balance_before`, `account_age_days`, `channel`, `txn_type`, `merchant_category`, `is_foreign`, `auth_error`

## tabformer: IBM TabFormer synthetic credit card transactions

synthetic US consumer card transactions for 2k users / 6k cards over ~30 years, chip/swipe/online, MCC, auth errors.

- source: <https://github.com/IBM/TabFormer>
- license: Apache-2.0 (repo)
- files: `card_transaction.v1.csv`
- notes: same data as kaggle ealtman2019/credit-card-transactions

Built: 24,386,900 rows, 29,757 fraud.

Fields observed: `amount`, `hour`, `dow`, `secs_since_prev_txn`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `cust_amount_mean_30d`, `amount_over_cust_mean`, `merch_txn_count_24h`, `cust_age`, `credit_limit`, `yearly_income`, `total_debt`, `fico_score`, `num_cards`, `channel`, `txn_type`, `merchant_category`, `card_brand`, `card_kind`, `is_foreign`, `cust_gender`, `auth_error`

## ulb: ULB / Worldline credit card fraud

real european card transactions, 2 days in sept 2013, features are PCA components except time and amount.

- source: <https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud>
- license: DbCL v1.0
- files: `creditcard.csv`
- notes: only amount + hour map onto the shared schema, V1..V28 live in their own block

Built: 284,807 rows, 492 fraud.

Fields observed: `amount`, `hour`, `txn_type`, `ulb_v1..v28`

## paysim: PaySim mobile money simulation

simulated mobile money transfers / cash in / cash out based on an african operator's logs, 1 month in hourly steps.

- source: <https://www.kaggle.com/datasets/ealaxi/paysim1>
- license: CC BY-SA 4.0
- files: `PS_20174392719_1491204439457_log.csv`
- notes: balances before/after for both parties. isFlaggedFraud is a rule output and is NOT used as a feature

Built: 6,362,620 rows, 8,213 fraud.

Fields observed: `amount`, `hour`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `balance_before`, `balance_after`, `dest_balance_before`, `dest_balance_after`, `channel`, `txn_type`, `dest_is_merchant`

## sparkov: Sparkov simulated credit card transactions

simulated US card purchases for 1k customers over 2019-2020 with merchant geo, customer demographics and 14 categories.

- source: <https://www.kaggle.com/datasets/kartik2112/fraud-detection>
- license: CC0 (kaggle listing)
- files: `fraudTrain.csv`, `fraudTest.csv`
- notes: train+test concatenated then re split by time like everything else

Built: 1,852,394 rows, 9,651 fraud.

Fields observed: `amount`, `hour`, `dow`, `secs_since_prev_txn`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `cust_amount_mean_30d`, `amount_over_cust_mean`, `merch_txn_count_24h`, `cust_age`, `dist_km`, `city_pop`, `channel`, `txn_type`, `merchant_category`, `card_brand`, `is_foreign`, `cust_gender`

## banksim: BankSim synthetic payments

agent based simulation of a spanish bank's card payments, 6 months in daily steps, 15 merchant categories.

- source: <https://www.kaggle.com/datasets/ealaxi/banksim1>
- license: see kaggle page
- files: `bs140513_032310.csv`
- notes: only day resolution, so hour is unobserved

Built: 594,643 rows, 7,200 fraud.

Fields observed: `amount`, `secs_since_prev_txn`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `cust_amount_mean_30d`, `amount_over_cust_mean`, `merch_txn_count_24h`, `cust_age`, `txn_type`, `merchant_category`, `cust_gender`

## ieee: IEEE-CIS / Vesta e-commerce fraud

real card not present e-commerce transactions over ~6 months, heavily anonymised.

- source: <https://www.kaggle.com/competitions/ieee-fraud-detection>
- license: Kaggle competition rules (non commercial)
- files: `train_transaction.csv`, `train_identity.csv`
- notes: train only (test has no labels). customer id reconstructed from card1+addr1+D1 the usual way

Built: 590,540 rows, 20,663 fraud.

Fields observed: `amount`, `hour`, `dow`, `secs_since_prev_txn`, `cust_txn_count_24h`, `cust_amount_sum_24h`, `cust_txn_count_7d`, `cust_amount_mean_30d`, `amount_over_cust_mean`, `account_age_days`, `ieee_dist1`, `ieee_c1`, `ieee_c13`, `ieee_c14`, `ieee_d15`, `channel`, `txn_type`, `card_brand`, `card_kind`, `device_type`, `product_code`, `email_bucket`
